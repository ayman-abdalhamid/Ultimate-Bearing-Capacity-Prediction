# Ultimate-Bearing-Capacity-Prediction
Developed machine learning models to predict the ultimate bearing capacity of shallow foundations on cohesionless soil.

• Prepared and cleaned experimental foundation data for machine learning.
• Applied feature engineering and preprocessing to geotechnical parameters.
• Developed and evaluated XGBoost and AdaBoost regression models.
• Used cross-validation and hyperparameter optimization for model selection.
• Applied symbolic regression to investigate interpretable mathematical relationships between input parameters and bearing capacity.
• Compared data-driven approaches with traditional analytical bearing-capacity methods.

Due to the lake of sufficient data, this model and the resulted equation shouldn't be used in real life design.
